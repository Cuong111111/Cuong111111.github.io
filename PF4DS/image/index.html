01 / DATASET OVERVIEW

One image, one diagnosis.

HAM10000 (Human Against Machine with 10,000 training images) is a collection of dermatoscopic images of common pigmented skin lesions. The notebook matches image filenames to the image_id and uses dx as the target label.

10,015unique image IDs found
10,015images matched to a target
7diagnostic classes

The metadata links each image through image_id and stores its diagnosis in dx. All 10,015 rows matched an image and a target label.

Kaggle dataset ↗

The target distribution is imbalanced: the nevus class (nv) contains about two thirds of the images. Class-aware evaluation and sampling should be considered in later modeling.

06 / DEEP LEARNING

DenseNet121, trained with lesion-aware splits.

The notebook extends the image analysis with transfer learning on the seven HAM10000 classes. Images are split by lesion_id so images of the same lesion cannot appear across training, validation, and test sets.

TRAIN6,41064.0%
VALIDATION1,60816.1%
TEST1,99719.9%

The split contains all 10,015 images and keeps the 7,470 lesion groups disjoint. Class proportions are broadly similar between splits, while the dataset remains strongly imbalanced: nv accounts for about 67%.

Training setup

ImageNet-pretrained DenseNet121; images padded and resized to 224 × 224; batch size 32. The classifier head is warmed up for 5 epochs, then the full network is fine-tuned for up to 25 epochs. Training-only augmentation and square-root inverse-frequency class weights address image variation and class imbalance. The selected checkpoint maximizes the validation score 0.5 × accuracy + 0.5 × macro-F1.

Target distribution and class-imbalance handling

How the notebook reduces class imbalance

Training uses weighted cross-entropy. Each class's loss weight is based on (largest training class count / that class's count)0.5. This gives rare classes more influence during learning and limits the dominance of the much larger nv class, without aggressively upweighting the rarest classes.

The notebook applies these weights to the training loss only; it does not duplicate minority images or remove majority images. Validation and test sets keep their natural distribution so evaluation reflects the dataset. The imbalance is therefore mitigated, not eliminated, which is why macro-F1 and per-class recall matter alongside accuracy.

Class similarity before fine-tuning

Class prototypes have high cosine similarity (about 0.92–0.98), showing substantial overlap in these ImageNet features. This is a pre-training diagnostic from train images, not the final HAM10000 classifier's performance.

Training and validation history

Loss decreases and validation scores improve during training. The validation curves level off and fluctuate in later epochs, so selecting the best validation checkpoint helps avoid relying on the last epoch by default.
